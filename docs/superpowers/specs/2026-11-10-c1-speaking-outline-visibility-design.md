# C1 Sprechen 提纲与答案显隐设计

## 目标

在 TELC C1 HS 的 Sprechen 练习页中修复提纲换行，并允许用户分别显示或隐藏提纲与示例答案。C1 页面不再显示 `Prüfen` 或 `Wiederholen`，因为录音不保存，也没有可检查的作答状态。

## 交互

- 提纲和答案默认可见，两个状态彼此独立。
- 提纲标题行右侧显示纯图标眼睛按钮；点击后只隐藏提纲正文，标题行保留，可再次展开。
- 答案标题行右侧显示纯图标眼睛按钮；点击后隐藏答案正文、录音与收藏控件，标题行保留，可再次展开。
- 图标按钮不显示可见文字，但必须提供随状态变化的中文 `aria-label` 和 `title`。
- 切换到另一个练习时，两部分恢复默认可见。

## 内容与布局

- 数组形式的提纲继续逐项显示；单项字符串内部以及非数组字符串中的换行符都按换行显示。
- 桌面端 Teil 1 继续左右两栏；窄屏继续单栏。按钮需要有足够的触控尺寸与清晰的键盘焦点。
- C1 各 Teil 的答案区域都提供答案眼睛开关；提纲开关只在存在提纲的 Teil 1 显示。
- B1/B2 的排序、`Prüfen`、`Wiederholen` 和保存逻辑保持不变。

## 实现边界

- 复用现有 `EyeIcon`，不新增依赖或通用抽象。
- 页面行为只修改 `SpeakingTeilExercisePage.jsx`、对应 CSS 和测试。
- 安全补充：答案收起导致录音器卸载时，必须停止麦克风并丢弃本次被中断的片段，不得覆盖此前完整的本地录音；用户主动停止的录音仍按现有行为保存。
- 不打开浏览器，不创建提交。
