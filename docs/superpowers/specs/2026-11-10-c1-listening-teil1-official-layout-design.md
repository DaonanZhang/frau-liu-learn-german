# C1 HS Hören Teil 1 官方布局

## 目标

让普通练习与模拟考试忠实呈现 TELC C1 Hochschule Hören Teil 1：十条 Aussagen（a–j）集中展示一次，八位 Sprecher/in 各自选择一条 Aussage。

## 方案

- 保留现有数据、question ID、保存和计分方向，不反转模型。
- 从题目选项生成共享 Aussagen 列表；每位 Sprecher/in 使用紧凑字母选择行。
- 批改后在对应 Sprecher 行显示正确/错误及正确陈述。
- 桌面显示完整字母行；平板和手机让字母选择自动换行，不产生横向溢出。

## 非目标

- 不修改 XLSX 合同、导入器、数据库或音频流程。
- 不改变 Hören Teil 2/3 或其他等级。
