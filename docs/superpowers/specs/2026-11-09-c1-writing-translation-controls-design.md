# C1 写作翻译与词汇浮层控件设计

## 意图

让 C1 HS 写作练习中的中文辅助内容可以一键显示或隐藏，并让固定在右下角的 Wortschatz 浮层可以收起，减少对写作区域的遮挡。Mock Exam 必须保持考试纪律：作答和选题期间不显示中文、翻译控件或 Wortschatz；仅在答案展示/自评阶段开放这些辅助功能。

## 方案

- 在 C1 写作标题后放置一个全局“中文翻译”开关，统一控制引语与 Wortschatz 条目中的中文；默认显示，以保持普通练习页当前行为。
- 在 Wortschatz 右上角放置独立的收起/展开按钮；收起时仅保留标题栏和展开控件，翻页与词条区域隐藏。
- 复用现有 `WritingExerciseWorkspace`，通过显式属性决定是否允许显示翻译控件与 Wortschatz。普通 C1 练习允许；Mock Exam 作答/选题阶段禁止；Mock Exam 写作自评阶段允许。

## 约束与非目标

- 不增加依赖，不为每条引语增加独立开关，不持久化开关状态。
- 控件使用原生按钮和 `aria-expanded`/明确的可访问名称。
- 桌面、iPad 和手机均保持可操作；Wortschatz 收起后不得继续遮挡正文。
- 不改动 B1/B2 写作交互，不创建 Git 提交。

## 2026-11-10 视觉与行为修订

- 中文翻译开关改为纯图标圆形按钮：显示中文时使用眼睛图标，隐藏后使用划线眼睛图标；按钮不显示文字，但保留动态中文 `aria-label` 与 `title`。
- Wortschatz 收起/展开改为纯图标圆形按钮：展开状态显示向上箭头，收起状态显示向下箭头；保留动态中文 `aria-label`、`title` 与 `aria-expanded`。
- 中文翻译开关只控制引语等非词汇表内容。Wortschatz 的中文释义始终显示，不受该开关影响。
- 普通详情页、Mock Exam `writing_review` 与 `results` 使用同一套图标与按钮样式。
