# 收藏词卡认识状态与备考收藏范围 UI 设计

## 目的

用户通过词典收藏单词后，可以在「德语卡片」页面将该收藏卡标记为“认识”或“不认识”。查询弹层保持简洁，只提供收藏与取消收藏。

## 已确认行为

- 认识状态属于“当前用户与收藏卡的关系”，不是词典词条的公共属性。
- 状态包含：未标记、认识、不认识。
- 新收藏默认未标记。
- 用户只在「德语卡片」页面设置认识状态，不在词典查询弹层设置。
- 取消收藏会删除该用户的认识状态；再次收藏时重新从未标记开始。
- 收藏词卡不与视频原有词卡做重复判断或状态联动。
- 切换到备考季后，左侧视频目录替换为考试目录，按考试类型和难度分层；当前显示 `TELC → B1 / B2 / C1`。
- 点击左侧难度切换对应收藏范围；主内容区不再显示“收藏范围”下拉框或重复的 B1/B2/C1 分段按钮，只保留当前范围标题和收藏数量。
- 考试目录与视频目录一样可以收起；移动端沿用目录抽屉，不产生横向溢出。
- 进入视频季且尚未选择父级或视频时，展示当前用户有权访问的全部视频词汇；进入备考季且尚未选择考试类型或难度时，展示该用户收藏的全部考试词汇。
- 点击视频季父级（例如科普季、Vlog季）后，先展示该父级下全部词汇，再允许继续选择具体视频。
- 点击考试类型父级（当前为 TELC）后，先展示该考试类型下全部收藏词汇，再允许继续选择 B1、B2 或 C1。

## 数据与接口

- 在 `UserExamVocabularyFavorite` 收藏关系上增加认识状态字段，复用现有三态语义。
- 收藏列表序列化返回该用户的认识状态。
- 增加仅修改当前用户收藏关系状态的接口操作。
- 非收藏卡不能通过该接口创建认识状态；必须先收藏。
- 收藏和取消收藏接口的现有权限与 `collection_key` 分类规则保持不变。

## 前端

- 所有收藏词卡都显示“认识”和“不认识”按钮，包括备考季收藏卡、视频季独立词典收藏卡。
- 点击当前已激活状态会恢复为未标记；点击另一个状态会直接切换。
- 状态筛选和计数继续使用现有“未标记 / 认识 / 不认识”语义。
- 视频原有 occurrence 卡继续使用原有标记接口；词典收藏卡使用收藏关系状态接口，二者互不推断。
- 查询弹层不展示认识状态按钮。
- 模拟考试进行阶段继续关闭词典；仅在 `results` 正确答案复盘和展示范文的 `writing_review` 阶段启用。
- `Sidebar` 根据来源显示两种内容：视频季显示模块和视频，备考季显示考试类型和难度。
- 当前只呈现后端已支持的 TELC B1、B2、C1，不为尚未支持的考试类型增加空入口。
- 左侧根级提供“全部视频词汇”或“全部考试词汇”状态；父级本身既负责进入下一层，也代表父级聚合范围。
- 视频聚合范围只包含当前用户有权访问的视频 occurrence 和对应视频收藏卡；考试聚合范围只包含当前用户自己的考试收藏卡。
- “全部”与父级聚合适用于单词和地道表达；视频句子仍属于具体视频，未选择具体视频时提示先选择视频，不批量加载所有字幕。

## 方案选择

### 采用：状态保存在收藏关系上

最符合“用户收藏的这张卡”的语义；无需新增状态表，取消收藏时自然删除状态，也能同时覆盖备考季和视频季。

### 未采用：复用视频 occurrence 标记

备考季没有 occurrence，且同一个词可能出现在多个视频位置，无法稳定表示收藏卡自身状态。

### 未采用：新增独立收藏状态表

能够保留取消收藏后的历史状态，但当前需求不需要，增加了额外模型、接口和清理逻辑。

## 验收标准

- 新收藏在德语卡片中显示为未标记，并可切换认识、不认识、未标记。
- 刷新页面后状态保持。
- 状态仅影响当前用户和当前收藏卡。
- 取消收藏后关系与状态一起删除。
- 查询弹层仍只有收藏/取消收藏。
- 模拟考试阅读、听力、写作和收卷等待阶段不挂载词典；答案复盘与写作范文自评阶段挂载正确考试范围的词典。
- 切换到备考季后，左侧显示 `TELC → B1 / B2 / C1`；三项正确切换收藏范围，目录可收起并兼容移动端抽屉。
- 视频季和备考季进入时均先展示各自全部词汇；科普季、Vlog季、TELC 父级分别展示其下全部词汇；具体视频或难度继续提供精确范围。
- 视频原有 occurrence 标记行为不回归。
- 后端测试、前端测试、生产构建和浏览器验收通过。
